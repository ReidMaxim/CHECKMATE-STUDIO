# Mission 003 · Storyteller

The documentary workflow takes a validated Mission 002 record, selects its highest-ranked candidate by default and performs a deeper search from the exact recorded move history. A candidate ID overrides selection. The default demo is Deep Blue–Kasparov game six. Both search settings and best, played and after-position lines go into the review JSON. The default depth is 17 and a mismatch in the preferred move or a change of at least 0.15 in estimated mover loss raises a disagreement flag. A disputed severity is kept out of the narration.

The language model is a constrained editor. It chooses an angle, hook, takeaway and ordered scene beats from a verified catalog. Chess statements are generated by replay or deep engine evidence. Arbitrary model prose, new facts, move IDs, CSS and code never enter the renderer. A generated draft therefore varies in narrative selection and sequence within the catalog. It does not exercise unrestricted AI prose. Engine alternatives use the renderer's variation mode, then return to the actual game. The claim ledger records references and marks editorial language separately from chess claims.

`npm test` runs the provider and planning checks. Use `python scripts/storyteller.py --mode offline` after installing Stockfish, Kokoro and both requirements files. `--candidate ply-16` overrides the editorial ranking. `--depth 17` sets the verification search. The resulting project is compiled and schema-checked by `npm run build`. Render with `npm run render -- storyteller-documentary`.

In GitHub Actions, branch pushes render the explicit offline demonstration. Manual live mode requires `OPENROUTER_API_KEY` as a repo secret and `STORY_MODEL` as a repo variable. A compatible service URL may be set through `STORY_API_URL` in the server environment. Use a trusted endpoint. The production workflow does not fall back silently when live mode fails. The module makes at most two requests with a 25-second timeout per request, and rejects invented or malformed IDs. GitHub requires the workflow on the default branch before manual dispatch is exposed.

The review bundle contains the verified evidence, structured script and claim ledger, deeper search, timing audit, storyboard and playable MP4. The generated dashboard allows inspection and playback; candidate selection is a review control, with production handled in Actions. The pipeline marks the delivered artifacts ready for human review after decoding the final file.
