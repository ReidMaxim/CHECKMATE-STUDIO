# Mission 003.1 · Live Director

The director edition evaluates three treatments with an editorial rubric (clarity 25%, originality 15%, factual support 25%, accessibility 15%, narrative structure 10%, visual feasibility 10%). Each dimension is authored as a 1–5 judgment and exposed in the review JSON. An explicit treatment can override the score. Deep Blue uses a dedicated evidence treatment after checking the exact move sequence and deep-search recommendation. Other candidates use the existing verified scene catalog and the same purpose-driven pacing.

The new edit emphasizes what White can do in the time Black gives it. It begins on the offered pawn, gives the critical reply and hypothetical alternative observation time, moves quickly through connective play, and ends by asking the viewer to count what the opponent can do before the capture. The Kokoro CPU path uses per-phrase speed and pause values. Alignment is phrase-level. There is no local language model.

Raw audio is checked for shape, rate, duration, nonfinite data, low energy, clipping and extended internal silence before file output. The portable profile uses one ONNX Runtime thread and disables graph optimizations. A rejected phrase is tried with standard graph settings. This is a bounded retry with fresh synthesis only. Motion timing uses the measured sample counts of the accepted phrases. Full MP4 decode and mixed audio checks run after export. The explicitly selected regression mode still uses the original prepared Kokoro takes.

The hosted path is OpenRouter-compatible and uses the existing structured planning contract. Rates and token counts are bounded, OpenRouter pricing is capped at zero, and request digest, attempts, provider response ID, model and usage metadata are retained where supplied. The live path requires the repository secret and model variable documented in Mission 003.

## Human review rubric

Give each cut 1–5 on factual accuracy, narrative clarity, hook, pacing, voice naturalness, visual direction, audio mix and engagement. A 1 means the cut needs major revision, 3 means usable with edits, 5 means ready for the intended audience. Record the moment or line behind each score. Use the verified claims and media checks for objective findings; leave audience enjoyment and naturalness open to phone playback review.
