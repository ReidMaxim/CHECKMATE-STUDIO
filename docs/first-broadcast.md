If no candidate clears the existing gate, the workflow exports the selection report. With OpenRouter credentials it uses the existing hosted author, editor and semantic review. Without them the report identifies the offline composition. The engagement report records the board, evidence, tradeoffs and optional interaction. An engine move is labeled as hypothetical.
