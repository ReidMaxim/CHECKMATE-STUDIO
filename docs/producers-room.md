# The Producer's Room

The producer scores verified moments across game records. A compact replay mechanism or an intelligible engine comparison can clear the gate. A visible but unexplained finish calls for revision. An isolated move with weak support or no teachable payoff is rejected. Scores measure the current director's ability to show the story. The report records weights, hooks, decision reasons, planned runtime and any manual selection.

Use the unseen-game workflow on the Producer branch. Branch pushes run the three-game shortlist and render one film. Inputs support a supplied PGN, an eligible candidate override, two voices, producer-only analysis, hosted writing, auditions, full rendering and offline regression. GitHub's manual dispatch requires the workflow on the default branch.

Hosted writing uses the existing OpenRouter secret and model variable. It accepts original sentences with restricted evidence IDs, allows one editorial revision, and checks both versions in a separate semantic review. Move legality and engine lines come from deterministic verification. Offline mode uses reusable motifs, with the draft and revision saved side by side. Auditions share one excerpt, rate, loudness target and model. The render uses af_heart provisionally.

The quality report separates measured checks from judgment. Signal checks and decoding catch audio and encoding faults. Caption timing within a phrase is estimated. Visual review checks representative frames, and a listener chooses the preferred voice.
